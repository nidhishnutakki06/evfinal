# SH_SmartEV_Management - 3D Digital Twin

This project implements the interactive 3D digital twin of the Smart EV Management campus using React Three Fiber.

## Quick Start

```bash
npm install
npm run dev
```

## Features
- **Real-time EVs**: SUV, Sedan, Hatchback, Scooter, Motorcycle
- **Charging Infrastructure**: Chargers, canopy shed, grid transformer
- **Dynamic Weather**: Time of day (Sunny, Cloudy, Rain, Night)
- **Power Flow Visualization**: Real-time energy particle flows
